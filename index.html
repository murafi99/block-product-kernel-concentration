05

Assumptions & Scope

A1 — Block-product structure
No entangling gate crosses a block boundary, at any depth. Circuit-topology statement; no randomness required.
A2 — Cross-block independence
Block-fidelity variables X₁,…,Xₘ are mutually independent over whatever source of randomness defines "variance." Breaks under shared, non-randomized re-uploading (Remark 2.1).
A3 — Per-block 1-design
Average block state is exactly maximally mixed: E[|ψᵢ⟩⟨ψᵢ|] = 𝟙/D. Needed for the main theorem.
A4 — Per-block 2-design
Block ensemble matches Haar to second moment. Needed only for Theorem 2 / the exact ceiling c(b).

What lies outside this hypothesis class

Interpolation Lab — Open Question 5

The paper poses two ways to interpolate between digitizing (c=1) and 2-design (c=c(b)), and notes the second one — the per-use random-coin construction — is "derived but not simulated." This tab simulates it live, alongside the static per-block-type partition, so you can see whether the linear and quadratic formulas actually diverge the way the paper predicts.

Static per-block-type partition (exact, Lemma 2)

clinear(p) = p·1 + (1−p)·c(b)

Per-use random-coin construction (derived in paper, not simulated there)

E[X²](p) = p²/D + (1−p²)·2/(D(D+1)) → cquad(p) = −log₂(E[X²](p)) / b

Derivation: with probability p² both draws are digitized (Bernoulli(1/D)); with probability (1−p)² both are Haar; with probability 2p(1−p) one is digit, one Haar — and a fixed vector against an independent Haar state is also exactly Beta(1,D−1), so that cross term contributes the same 2/(D(D+1)) as the pure-design case. That's why the (1−p)² and 2p(1−p) terms combine into (1−p²).

Points = Monte Carlo simulation of the random-coin construction (2,000 trials each). Curves = the two closed forms above.
